# React E-commerce App

A responsive e-commerce product listing UI built with React JS and Tailwind CSS. Product data is fetched from a local JSON Server API and displayed dynamically.

## Features

- Responsive product listing UI
- Dynamic product fetching from JSON Server
- Loading and error handling (if implemented)
- Reusable React components
- Tailwind CSS styling

## Tech Stack

- React JS
- JavaScript
- Tailwind CSS
- JSON Server

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start JSON Server using the project's configured command.
4. Start the React development server using `npm run dev`.

Check `package.json` for the exact scripts and API port used in this project.
